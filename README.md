Calculator App

A modern and responsive Calculator Web Application built using React, CSS, and Spring Boot.
This project combines a clean frontend UI with a powerful backend architecture to deliver fast and accurate calculations.

🚀 Features

-Modern and responsive UI

-Dark / Light inspired design

-Real-time calculations

-Smooth button animations

-Keyboard input support

-Error handling

-Calculation history support (optional)

-REST API integration with Spring Boot

-Mobile-friendly layout

🛠️ Tech Stack

-Frontend

  React,
  CSS3,
  Axios,
  Vite
  
-Backend

  Spring Boot,
  Java,
  Maven
